# ESQ2ARED

Public preview of the hand-painted clothing collection.

Website: https://kueim.github.io/esq2ared/

Product browsing and the local shopping bag are interactive previews. Payments, waitlist submissions, analytics, and the private owner dashboard are not connected in this static edition. No signup details are collected.

## Development

Run `npm ci` then `npm run dev`. Build with `npm run build`. Changes pushed to main deploy automatically through GitHub Actions.

Artwork and brand assets belong to their respective owners.
